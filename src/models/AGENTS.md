# Modeling Rules

- Keep the core lane GLM-family, penalized GLM, and lasso-credibility driven unless the user explicitly asks for an experimental challenger.
- Classify model changes as direct theory implementation, theory-compatible engineering support, betting overlay, or dashboard/reporting layer.
- Non-CAS model families may exist only as clearly labeled experimental challengers and must not become champions without written evidence.
- Preserve explicit market-offset, prior-offset, and complement logic. Do not hide market awareness inside opaque feature copying.
- Add or update tests for coefficient paths, penalty parameterization, feature-set traceability, leakage boundaries, and artifact metadata when touching model training behavior.
